## 根因(实证,非猜测)
错误窗原文(锁屏黑屏下用 UIAutomation 从 WebView2 无障碍树抠出 base64 HTML):
```
[Errno 2] No such file or directory:
C:\Users\...\Temp\onefile_23784_...\pypinyin\pinyin_dict.json
```
pypinyin 的拼音词典是**包数据文件,Nuitka 不会自动打包**。只有 server 角色在启动时
import 它(teacher/display 不碰),所以:源码跑没事、CI 测试没事、只有打成 exe 的
server 挂——8800 不监听、data 目录不建、错误窗常驻。

## v0.1.6 修了什么(20bed5a / 90a3c62 / 24d8273)
1. 两个 workflow 加 `--include-package-data=pypinyin`(治本)
2. `--smoke-server` 冒烟闸:构建后真起一次服务器再放行(Linux+Windows 双流水线都加了,
   这类「只有冻结包才炸」的 bug 从此在 CI 就被拦下)
3. **顺带抓到自更新致命 bug**:install_pending 原来改的是 Nuitka 临时解包 exe(用后即焚),
   新版永远装不上 = 每次启动重下载的死循环;已改 `sys.argv[0]`(部署位,wmic 实证)
4. 部署加固:bat 版本无关 + 重跑先杀进程;学校显示端钉死 127.0.0.1 免 UDP 发现被防火墙拦
